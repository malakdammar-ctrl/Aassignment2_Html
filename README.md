# Assignment 2 - HTML Registration Form

This repository contains my solution for **Assignment 2 (HTML Basics)** in **Web Development 1** at Al-Aqsa University.

## Overview
The goal of this assignment is to build a structured, accessible, and interactive user registration form using pure HTML, focusing on proper form organization, input types, labels, and built-in HTML validation attributes.

## File in This Repository
- `registration.html`: A complete user registration form divided into logical sections using `<fieldset>` and `<legend>`, covering personal information, account credentials, contact details, user preferences, technical skill level, and profile picture upload.

## Key HTML Elements Practiced
- **Form Structure & Grouping:** `<form>`, `<fieldset>`, `<legend>`, and `<div>`.
- **Labels & Inputs:** `<label>`, `<input>` (`text`, `email`, `password`, `tel`, `date`, `radio`, `checkbox`, `range`, `file`), `<select>`, `<option>`, and `<textarea>`.
- **Actions & Attributes:** `<button>`, `required`, `min`, `max`, `value`, and `accept`.

## How to View
1. Clone or download this repository to your computer.
2. Open `registration.html` directly in any web browser (such as Google Chrome, Microsoft Edge, or Firefox) to test the form.
