# Assignment 2 - HTML Basics

This repository contains my solution for **Assignment 2 (HTML Basics)** in **Web Development 1** at Al-Aqsa University[cite: 5].

## Overview
The goal of this assignment is to practice core HTML elements and document structure, including headings, paragraphs, images, lists, tables, and interactive input forms[cite: 1, 2].

## Files in This Repository
- `my-recipe.html`: A cooking recipe page built with semantic HTML elements, featuring a dish description and image figure, preparation info, ingredient quantities, ordered cooking steps, a nutrition table, and cooking tips[cite: 1, 2, 3, 4].
- `registration.html`: A user registration form organized into logical sections with input fields, selection menus, radio buttons, checkboxes, range input, file upload, and HTML form validation attributes.

## Key HTML Elements Practiced
- **Structure & Text:** `<h1>`, `<h2>`, `<p>`, `<hr>`, `<strong>`, and `<em>`[cite: 1, 2, 3, 4].
- **Media & Lists:** `<figure>`, `<figcaption>`, `<ul>`, and `<ol>`[cite: 1, 2, 3, 4].
- **Tables & Forms:** `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`, `<form>`, `<fieldset>`, `<legend>`, `<label>`, `<input>`, `<select>`, `<textarea>`, and `<button>`[cite: 1, 2, 3, 4].
